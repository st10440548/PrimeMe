# PrimeX (PrimeMe)

**PROG7314 — Android Application Development**

PrimeX is a native Android self-improvement application designed to help users manage personal goals, monitor progress, and organise their daily focus.

The application combines a Kotlin-based Android interface with Firebase authentication and an Azure-hosted REST API for cloud-based goal management.

## 1. Key Features

### Authentication and Security

- Google Sign-In using Firebase Authentication.
- Biometric app unlocking using supported fingerprint or facial authentication.
- Authentication checks before accessing protected application screens.

### Goal Management

- Create personal goals.
- View goals retrieved from the cloud backend.
- Mark goals as completed.
- Display progress using visual progress indicators.
- Preserve completed goals through backend storage.

### Multilingual Support

PrimeX supports English and isiZulu.

Users can switch languages through Settings. Their selected language is stored locally and remains available after restarting the application.

### Offline Mode

PrimeX stores a local copy of successfully synchronized goals.

When the internet connection is unavailable, users can view their previously synchronized goals.

**Current limitation:** Offline mode provides read-only access. Creating or completing goals requires an internet connection.

### Notifications

PrimeX supports local Android notifications following successful goal creation and completion.

The application requests notification permission on supported Android versions and provides a Daily Reminders preference.

**Current limitation:** Notifications are generated by application events rather than remote Firebase Cloud Messaging push notifications. Physical-device verification of the latest notification changes is pending.

### Personalised Settings

Users can configure:

- Display name.
- Daily focus target.
- Daily Reminders preference.
- Dark Mode preference.
- Preferred language.

Settings are saved using Android SharedPreferences.

**Note:** Some settings, including Dark Mode and Daily Reminders scheduling, are not yet fully connected to their intended visual or scheduling behaviour.

## 3. Application Architecture

PrimeX uses an Android frontend that communicates with an Azure-hosted backend.

```text
Android Application
        |
        +-- Jetpack Compose Screens
        |       |
        |       +-- Login
        |       +-- Home
        |       +-- Goals
        |       +-- Settings
        |
        +-- Firebase Authentication
        |
        +-- AndroidX Biometric
        |
        +-- SharedPreferences
        |       |
        |       +-- User Preferences
        |       +-- Offline Goal Cache
        |
        +-- Retrofit HTTP Client
                |
                v
        ASP.NET Core REST API
                |
                v
        Azure PostgreSQL Database
```

The Android application communicates with the backend through HTTP requests. The backend handles goal operations and database persistence.

## 4. Backend API

The application uses an Azure-hosted ASP.NET Core Web API.

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/goals` | Retrieve goals |
| POST | `/api/goals` | Create a goal |
| PATCH | `/api/goals/{id}/complete` | Mark a goal as completed |

The backend uses PostgreSQL to persist goal information.

## 5. Installation and Setup

### Requirements

- Android Studio.
- Android SDK.
- JDK compatible with the project's Gradle configuration.
- Android device or emulator running Android 8.0 (API 26) or later.
- Internet connection for Google Sign-In and cloud synchronization.
- Required Firebase configuration for the Android application.

### Clone the Repository

```bash
git clone https://github.com/st10440548/PrimeMe.git
cd PrimeMe
```

### Open in Android Studio

1. Launch Android Studio.
2. Select **Open**.
3. Select the cloned `PrimeMe` project directory.
4. Allow Gradle to synchronize dependencies.
5. Ensure the required Firebase configuration is available.
6. Select an Android device or emulator.
7. Run the application.

### Build from Terminal

```bash
./gradlew assembleDebug --no-daemon
```

The debug APK is generated at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 6. Testing

### Automated Testing

The repository contains a GitHub Actions workflow configured to run Android and backend build/test commands.

Android:

```bash
./gradlew testDebugUnitTest assembleDebug --no-daemon
```

Backend:

```bash
cd PrimeMeApi
dotnet test
```

These commands are configured in `.github/workflows/android.yml`.

### Physical Device Testing

The following functionality has been tested on a physical Android device:

- Google authentication.
- Goal retrieval from the Azure backend.
- Goal creation.
- Goal completion.
- Persistence of completed goals.
- English and isiZulu language switching.
- Biometric app unlocking.
- Viewing previously synchronized goals offline.

Notification functionality has compiled successfully, but the latest behaviour still requires physical-device testing.
