# AI Usage Declaration

**Project:** PrimeX (PrimeMe)  
**Module:** PROG7314  
**AI Tool:** OpenAI ChatGPT

## 1. Introduction

During the development of PrimeX, I made use of ChatGPT as a supporting tool to assist with certain aspects of programming, debugging, and understanding technical concepts.

The development process involved a combination of my own practical work, existing project code, research, and AI assistance. Rather than using AI as a replacement for the development process, I incorporated it into my workflow to help investigate problems, explore possible solutions, and improve the application's functionality.

## 2. How I Used AI During Development

### Programming Assistance

During development, I consulted ChatGPT when I needed assistance understanding or implementing particular functionality.

This included seeking guidance on aspects of biometric authentication, multilingual support, offline functionality, application settings, and Android notifications.

I also shared existing project code and implementation details with ChatGPT so that it could help identify necessary modifications, explain how different components interacted, and suggest improvements.

Some code was generated or modified by ChatGPT and subsequently incorporated into the project. These changes were reviewed and tested as part of the development process.

### Debugging and Code Corrections

One of the main ways I used ChatGPT was for debugging.

When I encountered unexpected behaviour, I described the issue and worked through possible explanations and corrections.

For example, while working with Android notifications, I noticed that disabling Daily Reminders did not consistently preserve the selected setting.

I identified and reported this problem, obtained guidance on how the preference should be stored, and applied the correction through my own Terminal.

I then created and pushed a Git commit containing the change.

This was an example of how AI assisted with problem-solving while I remained involved in identifying, implementing, and reviewing the correction.

### Technical Guidance and Understanding

ChatGPT also assisted with explaining development concepts, including:

- Android application architecture and Kotlin implementation.
- Persistent storage and offline data access.
- Firebase authentication and biometric security.
- Integration with an Azure-hosted backend.
- Git branching, commits, and pull requests.

These explanations helped me understand the technologies used and make decisions about how to proceed when developing or troubleshooting the application.

## 3. My Role in the Development Process

Throughout the project, I participated in development, integration, testing, and version control.

My responsibilities included configuring and using the development environment, running the application, testing functionality, identifying errors, applying corrections, and evaluating whether implemented features behaved as expected.

I performed tests on a physical Android device, including authentication, goal creation, goal completion, language switching, biometric unlocking, and offline goal access.

I also participated in GitHub workflows, reviewed feature changes, approved pull-request merges, and used Terminal to make and push my own code correction.

The project therefore involved an iterative process in which implementation, testing, feedback, and corrections informed subsequent development.

## 4. Benefits and Challenges of Using AI

AI assistance helped me approach technical challenges more efficiently and understand possible solutions to development problems.

However, I learned that AI-generated solutions are not necessarily correct or complete.

For example, the Daily Reminders functionality required further investigation after its initial implementation.

This highlighted the importance of independently testing functionality, examining application behaviour, and making corrections where necessary.

The experience also helped me develop practical skills in debugging, version control, and evaluating software functionality.

## 5. Conclusion

ChatGPT was used as a development support tool during the PrimeX project. It assisted with technical explanations, code generation and modification, troubleshooting, and development guidance.

My involvement included working with the existing application, identifying problems, integrating and testing changes, making corrections, and participating in decisions about the project's development.

The experience demonstrated how AI can support software development when combined with active developer involvement, practical testing, and critical evaluation.
